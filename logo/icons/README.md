# App icon exports

Generated by `scripts/export-icons.sh` from the approved logo SVGs in `logo/`,
without changing the artwork. Same method as byteowlz/xlatch
(`scripts/export-apple-icons.sh`). Rerun the script after any logo change.

- `macos/AppIcon.icns`: app bundle icon used by `scripts/release/macos.ts`, with
  the standard 16/32/128/256/512 pt sizes at 1x and 2x.
- `macos/ears_1024.png`: its master, from `ears_logo_mac_white_on_black.svg`. The
  rounded tile is fitted into a centered 896 px area of a transparent 1024 px
  canvas (64 px optical margin), so it matches other apps in the Dock.
- `ios/ears_1024.png`: opaque full-bleed 1024 px square without alpha, from
  `ears_logo_white_on_black.svg`. For a future iOS app or App Store marketing
  image; the OS applies its own mask.
- `linux/ears_<size>.png`: hicolor theme sizes 16-512 px.
- `windows/ears.ico`: 16-256 px.
- `apps/ears-ui/assets/tray/ears-mark.png`: the logo mark alone, white on
  transparent, for the tray/menu-bar icon (eaRS tints it with the island's state
  colours).

These are conventional flat exports, not a layered Icon Composer `.icon`
(oqto-mobile uses one for Liquid Glass on iOS/macOS 26). Create that before an
App Store submission.
